# Монополия Гранд-Тур

Настольная монополия в браузере: один файл, без сборки и без сервера.

* **Поле растёт от числа игроков.** До пяти игроков — классические 40 клеток,
  дальше каждая сторона удлиняется, на восьмерых круг доходит до 64 клеток.
* **Группы по три и по два участка** — самая дешёвая и самая дорогая группы парные.
* **Сделки:** обмен участками с доплатой и соглашение «не беру с тебя аренду N кругов».
* **Режимы стола:** порталы, казино, рокировка, джекпот на стоянке.
* **Паки оформления:** «Бренды» (вымышленные марки) и «Гомель» (улицы и районы),
  плюс свой пак из собственных картинок — имя файла становится названием клетки.
* **Боты** для игры в одиночку, **hot-seat** за одним устройством и **онлайн с чатом**.

## Онлайн

Онлайн-часть работает на Firestore. Нужен свой бесплатный проект:

1. `console.firebase.google.com` → создать проект.
2. Build → Firestore Database → Create database (можно в тестовом режиме).
3. Project settings → Your apps → Web → скопировать блок `firebaseConfig`.
4. В игре: вкладка «Онлайн с друзьями» → вставить конфиг → «Подключить».

Правила доступа для игры (минимум):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /profiles/{doc}   { allow read, write: if true; }
    match /rooms/{room}/{document=**} { allow read, write: if true; }
  }
}
```

Такие правила открыты всем, у кого есть ссылка на игру — для партии с друзьями этого
достаточно, для публичного сайта их стоит ужесточить.

Дальше: имя и код игрока, добавление друзей по коду, комната из пяти знаков —
друг вводит код и садится за стол со своего устройства.

## Локальный запуск

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000/`.
